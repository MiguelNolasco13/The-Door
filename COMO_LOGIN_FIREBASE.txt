THE DOOR - LOGIN FIREBASE

Esta versão usa:
- Firebase Authentication.
- Entrar com Google.
- Entrar e criar conta com e-mail e senha.
- Perfil de acesso vinculado a um condomínio por convite.
- Firestore para sincronizar os dados operacionais entre aparelhos.

ANTES DE PUBLICAR:
1. No Firebase Console > Authentication > Método de login, confirme Google ativado.
2. Se quiser e-mail/senha, ative também o provedor E-mail/senha.
3. Em Authentication > Configurações > Domínios autorizados, confirme o domínio usado pelo GitHub Pages.
4. Envie o conteúdo desta pasta para a raiz do repositório GitHub The-Door e aguarde a Action concluir.
5. Configure o primeiro proprietário conforme COMO_CONFIGURAR_FIRESTORE.txt.
6. Para um responsável de condomínio, use a Central Administrativa para cadastrar o condomínio e gerar o convite.

IMPORTANTE:
- O responsável convidado não escolhe o próprio condomínio.
- No primeiro acesso com e-mail/senha ou Google, o The Door valida o convite e cria o perfil usuarios/{UID} com o condominioId autorizado.
- Os dados operacionais ficam no Firestore, separados pelo condominioId.
- As fotos das encomendas permanecem no aparelho nesta etapa; elas ainda não são armazenadas na nuvem.
- Nunca coloque credenciais de conta de serviço ou chaves privadas no frontend.
